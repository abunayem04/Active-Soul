# Active Soul — Human Performance & Athletic System

> **"LESS, BUT BETTER."**  
> A world-class, precision-engineered athletic performance website inspired by global performance brands such as Nike, WHOOP, and Equinox.

---

## Brand Identity & Aesthetic

- **Design Philosophy**: Minimal, athletic, confident, performance-driven, and cinematic. Generous whitespace with strong typography hierarchy.
- **Color System**:
  - **Dominant Background**: `#FFFFFF` (Clean, spacious)
  - **Primary Text**: `#111111` (Deep athletic contrast)
  - **Secondary Text**: `#555555`
  - **Primary Accent**: `#B6FF00` (Electric Lime — used strategically for primary CTAs, active indicators, and telemetry highlights)
  - **Soft Accent**: `#E8FFB8`
  - **Secondary Background**: `#F5F5F2`
  - **Borders**: `#E5E5E5`
- **Typography Pairing**:
  - **Display / Headlines**: `Bebas Neue`
  - **Body / Interface**: `Inter`
  - **Metrics / Numbers**: `Space Grotesk`
- **Border Radius Standards**:
  - **Buttons**: `10px`
  - **Cards & Visuals**: `16px` max

---

## Core Features & Sections

1. **Minimal Navbar**: Transparent on hero; transitions to frosted backdrop blur with light border on scroll.
2. **Hero Visual Centerpiece**: High-resolution transparent runner visual with staggered multi-line reveals and live telemetry HUD badges (Heart Rate Zone 4 + Cadence).
3. **Trust & Performance Metrics**: Viewport-triggered animated count-up counters (10K+ members, 150+ coaches, 94% achievement, 4.9/5 rating).
4. **Goal Selection Pathway**: 5 interactive editorial panels with lime accent reveal and arrow micro-interactions.
5. **Training Programs**: Asymmetrical editorial cards for Strength, Running, Performance, and Mobility.
6. **4-Phase Training System**: Interactive methodology timeline (`ASSESS` → `PLAN` → `TRAIN` → `PROGRESS`).
7. **Coaches Faculty**: Profiles of elite coaches with 1.03x subtle zoom and focus tags.
8. **Results & Transformations**: Interactive before/after split comparison slider and real biometric progression deltas.
9. **Connected Telemetry HUD**: Athletic dashboard tracking Strain, Recovery, HR Zones, and Biomechanics with animated SVG curve charts.
10. **Testimonials**: Oversized quote typography with smooth transitions.
11. **Pricing & Membership**: Transparent 3-tier membership with Monthly/Annual billing toggle.
12. **Final Cinematic CTA**: Full-width canvas featuring the Olympic sprinter in starting blocks.
13. **Interactive Onboarding Modal**: 3-step athletic intake flow with custom program recommendation.

## Getting Started

Run locally using any static file server:

```bash
# Using Python
python -m http.server 8080

# Or using Node
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
